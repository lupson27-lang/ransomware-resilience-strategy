# Executive Summary

## Scenario
This project simulates a ransomware attack on a mid-sized hybrid enterprise environment.

## Key Risks Identified
- Credential compromise leading to lateral movement
- Ransomware encryption of critical systems
- Backup compromise due to insufficient isolation
- Lack of tested recovery procedures

## Response Overview
The incident response prioritized:
1. Identity containment
2. System isolation
3. Backup protection
4. Controlled recovery

## Key Improvements
- Implementation of immutable and air-gapped backups
- Strengthening identity security (MFA, least privilege)
- Network segmentation to limit lateral movement
- Regular disaster recovery testing

## Outcome
The attack was contained before full ransomware deployment, preserving recovery capability and minimizing business disruption.
